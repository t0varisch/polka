# Полка

Одна книга — три способа читать: страницами, как в обычной читалке, по одному слову, как в [Точке](https://github.com/t0varisch/tochka), или печатая, как в [Печатке](https://github.com/t0varisch/pechatka). Место в книге общее: переключил режим — продолжаешь с того же слова. Открывает FB2 (и fb2.zip), EPUB, TXT, PDF

На компьютере (Chrome, Edge) книги и прогресс лежат в папке на диске: выбираешь папку, приложение показывает книги из неё и пишет место в `.polka\progress.json` в этой же папке. На телефоне книги хранятся в браузере, как в Точке

## Управление

Страницы
- вперёд: стрелка вправо, PageDown, пробел, колесо вниз, тап по правым двум третям экрана, свайп влево
- назад: стрелка влево, PageUp, Shift+пробел, колесо вверх, тап по левой трети, свайп вправо
- место в книге — первое слово открытой страницы
- рисунки из FB2 и EPUB стоят на страницах между абзацами, подпись под ними другим шрифтом; нажатие на рисунок открывает его на весь экран, нажатие в любом месте, Escape или «Закрыть» возвращает на страницу

По слову
- пуск и пауза: кнопка «Читать», пробел или K, тап по сцене
- стрелки влево и вправо — предложение назад и вперёд, вверх и вниз — скорость
- на паузе виден текст вокруг слова

Печать
- печатаешь слова с ленты, курсор стоит на первом ненапечатанном; ошибка не сдвигает место
- Escape — в библиотеку

Во всех режимах: оглавление, закладки и ползунок положения — кнопка «Оглавление и закладки» в шапке книги, B — закладка (вне печати)

## Разработка

```
npm install
npm run dev      # локально
npm test         # модульные тесты
npm run build    # сборка в dist/, перед e2e и офлайн-проверкой обязательна
```

## Проверки

Сквозная проверка `scripts/e2e.mjs` берёт собранный `dist/`, сам поднимает на нём `vite preview` на свободном порту и гасит только его. Режим браузера: импорт, страницы вперёд, смена размера окна и размера текста (слово остаётся на странице), «По слову» с пуском, «Печать» на два слова, возврат в «Страницы», перезагрузка. Режим папки (`?testfolder`, только chromium): книга в OPFS, три страницы вперёд, место в `.polka/progress.json`. Снимки каждого шага — в `OUT`, код выхода не 0 при любом провале

```
BOOK=путь/к/книге.fb2 node scripts/e2e.mjs
BOOK=... SIZES=390x844,320x640,1280x800 BROWSER=chromium|webkit BASE=http://localhost:4173/ OUT=test-output node scripts/e2e.mjs
```

В WebKit режим папки пропускается: там нет `showDirectoryPicker`, а запись в OPFS в Safari идёт только из воркера

Офлайн-проверка `scripts/offline-check.mjs`: книга добавлена с сетью, потом сеть выключена, перезагрузка, чтение во всех трёх режимах. EPUB и PDF без сети — по желанию, через `EPUB=` и `PDF=`

```
FB2=путь/к/книге.fb2 node scripts/offline-check.mjs
```

Иконки: `node scripts/make-icons.mjs` (нужен Chrome), исходник — `public/icon.svg`
